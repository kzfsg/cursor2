# Ego - Text Input

A beautiful, minimalist text input with glass morphism design.

## Features

- **Glass Morphism Design**: Beautiful frosted glass effect with backdrop blur
- **Responsive Layout**: Works on desktop and mobile devices
- **Smooth Animations**: Subtle hover and focus effects
- **Modern Typography**: Custom fonts and elegant styling
- **Accessibility**: Keyboard navigation and screen reader support

## Quick Start

```bash
# Install dependencies
npm install

# Start the development server
npm start
```

The application will open in your browser at `http://localhost:3000`.

## Usage

Simply type in the text input field and press Enter to submit. The input features:

- Real-time text processing
- Beautiful glass morphism styling
- Smooth animations on hover and focus
- Responsive design that works on all devices

## Customization

The styling can be customized by editing `frontend/styles.css`. The design uses CSS custom properties for easy theming.
